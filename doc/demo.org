Demo for Maple org support.

* Session support

The :session parameter uses a string to identify a Maple kernel.
In the following examples, the string "foo" identifies ...

#+begin_src maple :session foo :results output
p := 10;
#+end_src

#+RESULTS:
: p := 10

#+begin_src maple :session foo :results output
q := p^2;   # remembers p from the previous block
#+end_src

#+RESULTS:
: q := 100

#+begin_src maple :results value
p := 3;
q := p^4;
#+end_src

#+RESULTS:
: 81

** Inline graphics generation and inclusion
Last command in block needs to be the plot (or a variable contain a plot).

#+begin_src maple :session plt :results graphics file :file sine.png :width 200 :height 100
plot(sin(3*x), x = 0..2*Pi):
#+end_src

#+RESULTS:
[[file:sine.png]]

#+begin_src maple :results graphics file :file sine2.png
plt := plot(sin(2*x), x = 0..2*Pi):
plt;
#+end_src

#+RESULTS:
[[file:sine2.png]]


* Latex output

Optional =:latex yes= option, captures latex from last output
=:results output drawer= is needed.

For simple output no extra packages are needed.

#+begin_src maple :session foo :results output drawer :latex yes
f := a*x^2 + d:
latex(f);
#+end_src

#+RESULTS:
:results:
\[a \,x^{2}+d\]
:end:


#+begin_src maple :session foo :results output drawer :latex yes
f := int(g(x),x):
latex(f);
#+end_src

#+RESULTS:
:results:
\[\int g \! \left(x \right)d x\]
:end:


For more advanced output include the =maple.sty= file found in "etc"
under the maple install.

#+begin_src maple :session foo :results output drawer :latex yes
latex(Int(1/(x^2+1), x));
#+end_src

#+RESULTS:
:results:
\[\textcolor{gray}{\int}\frac{1}{x^{2}+1}\textcolor{gray}{d}x\]
:end:

#+begin_src maple :session foo :results output drawer :latex yes
latex(Product(k, k=1..n));
#+end_src

#+RESULTS:
:results:
\[\moverset{n}{\munderset{k =1}{\textcolor{gray}{\prod}}}\! k\]
:end:


* Load the Maple latex package

Define this helper in your Emacs configuration:

#+begin_src emacs-lisp
(defun my/org-add-latex-package (package &optional options snippet)
  "Buffer-local add PACKAGE to `org-latex-packages-alist'.
SNIPPET non-nil means the package is ALSO used when rendering inline
LaTeX previews; nil means export-only.  Use nil for listings-type
packages (lstmaple): including them in the preview preamble breaks the
tight bounding box and makes inline math images very tall."
  (make-local-variable 'org-latex-packages-alist)
  (add-to-list 'org-latex-packages-alist
               (list (or options "") package snippet)))
#+end_src

#+RESULTS:
: my/org-add-latex-package

Then activate the packages with a file-local block at the very END of this file
(one =eval:= line per package) — see the bottom of this buffer, which loads both
=maple= and =lstmaple=.
